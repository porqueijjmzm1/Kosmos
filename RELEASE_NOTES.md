## What's new in v3.7.0

- **Save rate**: a new slider in the menu's **Buffer** tab (and in the mod settings) that sets the chance, from 0% to 100%, that each save goes ahead.
  - At **100%** (the default) every click the buffer can save is saved, as before.
  - At **50%**, only about half of them are; the others go through exactly as you clicked them, as if the buffer were off for that click.
  - It counts for every kind of save: normal saves, orb alignment and more time at death spots.
- While the rate is under 100%, the menu's header shows it (like `ON | 2f | 60%`), and the console logs each save that didn't go ahead as **NOT SAVED**.

## Install

Put Kosmos.geode in your Geode mods folder and remove older copies (InputBuffer.geode, TESTEBUFFER.geode or basu.input-buffer.geode), or both run at once. On iOS, upload it with the Geode launcher's web upload (see the [website](https://porqueijjmzm1.github.io/Kosmos/#install)).
