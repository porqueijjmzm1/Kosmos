v3.5.0 · Geode mod for Geometry Dash

Early clicks,
right on time.

Kosmos is an input buffer. When you click a little too early, it runs your path ahead in a hidden copy of the level, and holds the click until the tick where it works. Clicks that are already fine go straight through.

Features

A second chance for every early click

Everything the buffer does, and what it gives you around it.

Up to 8 frames of room

Pick how early a click may be: 0.5, 1, 2, 4, 6 or 8 frames, your own custom amount, or off. Every game mode can also have its own limit.

Sees what's coming

The hidden ghost plays your next ticks with the real physics: orbs, pads, gravity and speed portals, mode portals, move triggers and moving objects.

Smart in every mode

Cube, ship, ball, UFO, wave, robot, spider and swing each get their own rules, like feathering in ship, hold lengths for robot and spam handling in wave.

No stutter

All the predictions in a frame share a small slice of it, and a long search carries on over the next ticks. Low latency mode keeps fast clicks untouched.

Learns your levels

Level memory remembers which delays worked at each spot and where you keep dying, and gives you more room there. A heatmap shows your deaths on the progress bar.

Tools to practise

A timing meter shows how early each click was, and the save map marks where you were saved. Path view draws where an input would take you; training mode only gives hints. Save the setup you like as a profile and share its code.

Nine animated themes

Deep space, planets and phenomena: each theme redraws the whole menu with its own moving art. Stars drift, comets fall, the aurora waves.

Updates itself

When a new version is out, a window shows what's new and asks before downloading. Settings are saved as you go, so a crash never loses them.

How it works

Three steps, in a few milliseconds

  1. 1

    You click

    Before the click reaches the game, Kosmos asks: would it work right now?

  2. 2

    The ghost tries it

    A hidden copy of your player runs the next ticks with the click now, then a tick later, then later still, up to your stage's limit.

  3. 3

    It lands on time

    If now is fine, the click goes straight through. If now crashes and a later tick survives, the click is held until that tick.

Your click
Reaches the game

A click 3 ticks early is held, then lands on the tick where the jump clears the spikes.

Install

Ready in a minute

  1. Get Geode

    Kosmos is a Geode mod. Install Geode for Geometry Dash 2.2081 first.

  2. Download Kosmos

    Kosmos.geode: one file for Windows, Android, iOS and macOS.

  3. Put it in the mods folder

    Open the game's folder (on Steam: right-click Geometry Dash, Manage, Browse local files) and put the file in:

    geode\mods

    With a file manager, put the file in:

    Android/media/com.geode.launcher/game/geode/mods

    On iOS, Geode runs through the Geode launcher (mods fully work with JIT). Add the file with the launcher's web upload:

    1. In the launcher's settings, hold iOS Launcher (in About) for 3 seconds and tap Yes to turn on Developer Mode.
    2. Turn on Web Server at the bottom of the settings, then restart the launcher.
    3. On a computer on the same Wi-Fi, open this address and upload the file:
    http://<your iPhone's IP>:8080

    In Finder, press Cmd Shift G and go to:

    ~/Library/Application Support/GeometryDash/geode/mods

  4. Restart the game

    Open the menu with the Saturn button on the main menu or the pause menu, Right Shift, or 7 in a level.

Coming from Input Buffer?

Kosmos is the same mod with a new name, so your settings carry over. Delete the old file (InputBuffer.geode, TESTEBUFFER.geode or basu.input-buffer.geode) or both will run at once.

Updates

You only install once. When a new version is out, a window on the main menu shows what's new and asks before downloading.

FAQ

Questions

Can I use it for leaderboards or demon lists?

Kosmos changes when your clicks reach the game, and many leaderboards and lists don't accept runs made with mods like that. Check the rules before you submit a run. While the buffer is on, levels show a small label in the corner. To practise without changing a single click, turn on Training mode: it only shows hints.

My clicks feel delayed. What do I do?

Keep Low latency mode on (it is by default): fast clicks are never shifted. You can also pick a smaller stage, like 1f or 2f, or give each game mode its own limit in the Frames tab.

The game stutters when I click.

Keep Auto time budget on (it is by default) so predictions share a small part of each frame. On slow PCs, turn on Performance mode as well.

Does it work with Click Between Frames?

Yes. With Click Between Frames sync on, the prediction starts from the exact moment inside the tick where your click landed.

Does it work on phones?

Yes, on Android and iOS. Without a keyboard, open the menu with the Saturn button on the main menu or in the pause menu.

How do I change the theme?

In the menu's Themes tab, or the Menu theme setting in Geode. You can also try them on this page.

I found a bug.

Open an issue on GitHub or tell us on Discord. The console log helps a lot: press F8 in a level (or Tools, Copy log) and paste it.
